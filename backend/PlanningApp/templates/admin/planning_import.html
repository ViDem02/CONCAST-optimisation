File Format Requirements:

CSV Timetable Format:

  • First column: Time (format: YYYY-MM-DD HH:MM:SS)
  • Remaining columns: Process names (values: 0 or 1)
  • 1 = process is active, 0 = process is inactive
  • Each row represents a 15-minute interval
Time,Process1,Process2,Process3
2024-01-01 00:00:00,1,0,1
2024-01-01 00:15:00,1,0,1
2024-01-01 00:30:00,0,1,1

YAML Configuration Format:

  • Define processes with their properties
  • Process names must match CSV column headers
  • Required fields: electricity_consumption_kWh
  • Optional fields: max_forward_minutes, max_backwards_minutes
processes:
  Process1:
    electricity_consumption_kWh: 100
    max_forward_minutes: 60
    max_backwards_minutes: 30
  Process2:
    electricity_consumption_kWh: 150
    max_forward_minutes: 0
    max_backwards_minutes: 0
