File formats

CSV timetable: a Time column and one column per process with 1 (running) or 0 (stopped), one row every 15 minutes from Monday 00:00 to Sunday 23:45.

Time,s_finit,b_past
2025-09-22 00:00:00,1,0
2025-09-22 00:15:00,1,0
2025-09-22 06:45:00,1,1

YAML file: for every process, its power while running (kW) and how many minutes its shifts may start later or earlier (0 = fixed).

processes:
  s_finit:
    electricity_consumption_kWh: 100
    max_forward_minutes: 0
    max_backwards_minutes: 0
  b_past:
    electricity_consumption_kWh: 278
    max_forward_minutes: 120
    max_backwards_minutes: 120
