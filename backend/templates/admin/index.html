How to use SPARC

  1. Input data — upload the hourly on-site generation, the electricity prices and (for cold rooms) the outside temperature as CSV files. The CONCAST data are already loaded.
  2. Production plans — import a weekly plan (CSV timetable + YAML) and set, per shift, how many minutes it may start earlier or later.
  3. Shift optimisation — pick a plan and a reference week, then press Save and calculate. A new, optimised plan is created.
  4. Cost simulations — compare the current and the optimised plan over any period (for example a whole season) to check the savings hold.

Charts of every result are on the results website.
